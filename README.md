# 🎮 Trashborn - PSX-style Roguelike Action Game

![Trashborn Logo](https://i.postimg.cc/XqBqxc1J/gamelogo.png)

**Official website for the retro-inspired roguelike action game Trashborn**

## 🌟 About the Project

Trashborn is a love letter to late 90s/early 2000s gaming with:
- Authentic PSX-style low-poly graphics
- Roguelike mechanics with permadeath
- Crunchy melee combat system
- Procedurally generated wastelands
- Retro aesthetic with CRT filter effects

This website mimics the look and feel of early 2000s game sites with:
- Scanlines and CRT effects
- PSX-inspired UI elements
- Retro color scheme
- "Under Construction" vibes

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first styling
- **CSS Animations** - Scanlines, glitch effects
- **Font Awesome** - Retro icons
- **Responsive Design** - Works on modern and old-school resolutions
